🌧️ Rainfall Analysis in India
📌 Overview

This project performs Exploratory Data Analysis (EDA) on rainfall data across India from 1901 to 2015. The analysis focuses on understanding annual, monthly, seasonal, and subdivision-wise rainfall patterns.

📂 Dataset

The dataset contains rainfall records for different Indian subdivisions, including:

Monthly rainfall (January–December)
Seasonal rainfall
Annual rainfall
Year and subdivision information
🛠️ Tools & Libraries
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook
🔍 Analysis Performed
Data cleaning and missing-value handling
Annual rainfall trend analysis
Monthly and seasonal rainfall analysis
Subdivision-wise rainfall comparison
Correlation analysis
Visualization of rainfall patterns
Individual subdivision/state-level analysis
📊 Key Insights
Rainfall varies significantly across Indian regions.
June–September contributes a major share of annual rainfall in many regions.
July and August are among the major rainfall months.
Western and northwestern regions generally receive less rainfall compared with northeastern and coastal regions.
Significant year-to-year variation in rainfall is observed.
